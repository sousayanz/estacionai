🚗 Estacionaí
Conectando motoristas a vagas de estacionamento de forma simples e inteligente.

O Estacionaí é uma plataforma digital desenvolvida com a proposta de conectar motoristas que procuram vagas de estacionamento a proprietários que desejam disponibilizar suas garagens.

O projeto busca simplificar a descoberta, a divulgação e a gestão de vagas, criando uma experiência digital intuitiva para os dois lados do marketplace.

Atualmente, o projeto está em desenvolvimento como um MVP (Minimum Viable Product), com foco na experiência visual, navegação e demonstração das principais funcionalidades.

🎯 Objetivo do projeto

Desenvolver uma solução digital que facilite o acesso a vagas de estacionamento, permitindo que motoristas encontrem opções próximas e que proprietários possam divulgar e administrar seus espaços.

O Estacionaí possui dois ambientes principais:

🚘 Para motoristas
Busca de garagens disponíveis.
Visualização de estacionamentos próximos.
Consulta de informações e características das garagens.
Visualização de preços e avaliações demonstrativas.
Processo de reserva simulado.
Histórico de reservas.
Gerenciamento de perfil.
🏠 Para proprietários
Cadastro e divulgação de garagens.
Gerenciamento de vagas.
Controle demonstrativo de disponibilidade.
Visualização de reservas recebidas.
Gerenciamento de anúncios.
Painel com indicadores demonstrativos.

🖥️ Tecnologias

O projeto utiliza tecnologias voltadas ao desenvolvimento de interfaces web modernas e responsivas.

HTML5: estruturação das páginas.
CSS3: estilização e responsividade.
JavaScript: interações e funcionalidades do protótipo.

A arquitetura poderá evoluir para React, TypeScript e outras tecnologias conforme a expansão do projeto.

📱 Responsividade

Smartphones.

🚀 Como executar o projeto
1. Clone o repositório
bash
git clone https://github.com/SEU-USUARIO/estacionai.git

2. Entre na pasta
bash
cd estacionai

3. Execute o projeto

Como o projeto utiliza HTML, CSS e JavaScript, você pode abrir o arquivo index.html diretamente no navegador.

Recomendamos utilizar a extensão Live Server no Visual Studio Code para facilitar a visualização durante o desenvolvimento.

Abra o projeto no VS Code.
Instale a extensão Live Server.
Clique com o botão direito em index.html.
Selecione Open with Live Server.

O projeto será aberto no navegador.

🧪 Ambiente de demonstração

O Estacionaí está sendo desenvolvido inicialmente sem integração com backend.

Algumas funcionalidades utilizam interações demonstrativas e dados simulados.

Não são realizadas cobranças reais, reservas comerciais ou autenticações reais nesta versão.

🎓 Contexto acadêmico

O Estacionaí é um projeto acadêmico com potencial de evolução comercial.

A proposta é aplicar conceitos de desenvolvimento de software, design de interfaces, experiência do usuário e modelos de negócio digitais na construção de uma plataforma de marketplace.

O projeto também busca explorar oportunidades de digitalização e melhor aproveitamento de espaços de estacionamento.
